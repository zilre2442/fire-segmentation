# 数据路径更新说明

## 更新日期
2024-11-16

## 更新内容

### 1. 数据集迁移
将原本存储在项目目录 `dataset/` 下的数据集文件迁移到了服务器数据盘：

- **ActiveFire数据集**
  - 原路径：`dataset/activefire/`
  - 新路径：`/data/heguozhen/Fire/activefire/`
  
- **Land8Fire数据集**
  - 原路径：`dataset/Land8Fire/`
  - 新路径：`/data/heguozhen/Fire/Land8Fire/`

### 2. CSV文件路径更新
已自动更新所有数据集划分CSV文件中的路径，包括：

#### 主数据集划分
- `data/splits_activefire/*.csv` (5个算法 × 3个split = 15个文件)
  - voting, Kumar-Roy, Murphy, Schroeder, intersection
  - train, val, test
  
- `data/splits_land8fire/Land8Fire_*.csv` (3个文件)
  - train, val, test

#### 按火点数量划分的子数据集
- `data/splits_activefire/by_fire_pixels_voting/*/` (12个文件)
  - train, val, test × 4个类别 (very_few, few, many, very_many)
  
- `data/splits_land8fire/by_fire_pixels/*/` (12个文件)
  - train, val, test × 4个类别 (very_few, few, many, very_many)

**总计更新**: 42个CSV文件

### 3. 火点数量类别定义
- **very_few**: 1-10 像素
- **few**: 10-100 像素
- **many**: 100-1000 像素
- **very_many**: >1000 像素

## 训练和评估脚本更新

### 训练脚本
`exp/train_scripts/train_RGS_Net_V3_1.py`

**新增功能**：
- 支持选择按火点数量划分的子数据集进行训练
- 新增命令行参数 `--fire-category` 来选择类别

**使用示例**：
```bash
# 全量数据训练
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py

# 训练 very_few 类别（1-10像素）
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category very_few

# 训练 many 类别（100-1000像素）
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category many --epochs 150
```

### 评估脚本
`exp/eval_scripts/eval_RGS_Net_V3_1.py`

**新增功能**：
- 支持选择按火点数量划分的子数据集进行评估
- 新增命令行参数 `--fire-category` 来选择类别

**使用示例**：
```bash
# 全量数据评估
RANK=0 WORLD_SIZE=1 LOCAL_RANK=0 python exp/eval_scripts/eval_RGS_Net_V3_1.py --batch-size 64 --save-dir output/RGS_Net_V3_1/voting_date

# 评估 very_few 类别
RANK=0 WORLD_SIZE=1 LOCAL_RANK=0 python exp/eval_scripts/eval_RGS_Net_V3_1.py --fire-category very_few --save-dir output/RGS_Net_V3_1/voting_very_few_date

# 评估 few 类别
RANK=0 WORLD_SIZE=1 LOCAL_RANK=0 python exp/eval_scripts/eval_RGS_Net_V3_1.py --fire-category few --save-dir output/RGS_Net_V3_1/voting_few_date
```

## 命令行参数说明

### 训练脚本参数
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--data-root` | str | `data/splits_activefire` | 数据集根目录 |
| `--algorithm` | str | `voting` | 数据集算法类型 |
| `--fire-category` | str | `None` | 火点数量类别 |
| `--batch-size` | int | 64 | 批大小 |
| `--epochs` | int | 200 | 训练轮数 |
| `--lr` | float | 3e-4 | 学习率 |
| `--save-dir` | str | 自动生成 | 结果保存目录 |

### 评估脚本参数
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--data-root` | str | `data/splits_activefire` | 数据集根目录 |
| `--algo` | str | `voting` | 数据集算法类型 |
| `--fire-category` | str | `None` | 火点数量类别 |
| `--batch-size` | int | 64 | 批大小 |
| `--save-dir` | str | 需指定 | 模型权重所在目录 |

## 数据验证

可以运行测试脚本验证数据路径配置是否正确：

```bash
conda activate fire
python test_data_loading.py
```

该脚本会测试：
- ActiveFire全量数据集加载
- Land8Fire全量数据集加载
- 各个火点数量类别的子数据集加载

## 注意事项

1. **数据目录权限**：确保 `/data/heguozhen/Fire/` 目录有正确的读取权限
2. **硬盘空间**：原 `dataset/` 目录下的文件已移动，可以删除空目录
3. **环境依赖**：确保使用 `fire` conda环境运行训练和评估脚本
4. **分布式训练**：使用 `torchrun` 启动分布式训练时会自动设置必要的环境变量
