```bash
conda activate fire

```

## 训练示例

### 1. 全量数据训练（默认）
```bash
# 使用4张GPU训练
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py

# 使用1张GPU训练
CUDA_VISIBLE_DEVICES=0 torchrun --nproc_per_node=1 exp/train_scripts/train_RGS_Net_V3_1.py
```

### 2. 按火点数量分类训练

#### 训练 very_few 类别（1-10像素，占85%）
```bash
# 适合用于优化小火点检测
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category very_few \
  --epochs 200 \
  --batch-size 64
```

#### 训练 few 类别（10-100像素，占13%）
```bash
# 适合用于中等火点检测
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category few \
  --epochs 150 \
  --batch-size 64
```

#### 训练 many 类别（100-1000像素，占1.3%）
```bash
# 适合用于大火点检测
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category many \
  --epochs 100 \
  --batch-size 32
```

#### 训练 very_many 类别（>1000像素，占0.01%）
```bash
# 极少样本，仅用于验证
torchrun --nproc_per_node=1 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category very_many \
  --epochs 50 \
  --batch-size 4
```

### 3. 自定义训练参数
```bash
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category few \
  --algorithm voting \
  --epochs 150 \
  --batch-size 64 \
  --lr 3e-4 \
  --save-dir output/RGS_Net_V3_1/custom_few_training
```

## 实验策略建议

### 策略1: 分层训练
针对不同火点大小训练专门模型，然后根据预测火点大小选择相应模型
```bash
# 训练3个模型
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category very_few
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category few
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category many
```

### 策略2: 渐进式训练
先在小火点上训练，然后在大火点上微调
```bash
# 第一阶段：very_few
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category very_few \
  --epochs 100 \
  --save-dir output/stage1_very_few

# 第二阶段：few（从stage1加载权重）
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py \
  --fire-category few \
  --epochs 50 \
  --save-dir output/stage2_few
  # 注：需要修改脚本支持加载预训练权重
```

### 策略3: 对比实验
训练全量模型和分类模型，对比在各类别上的表现
```bash
# 全量模型
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py

# very_few专用模型
torchrun --nproc_per_node=4 exp/train_scripts/train_RGS_Net_V3_1.py --fire-category very_few

# 在各类别上评估两个模型
for cat in very_few few many very_many; do
  RANK=0 WORLD_SIZE=1 LOCAL_RANK=0 python exp/eval_scripts/eval_RGS_Net_V3_1.py \
    --fire-category $cat \
    --save-dir output/RGS_Net_V3_1/voting_full
    
  RANK=0 WORLD_SIZE=1 LOCAL_RANK=0 python exp/eval_scripts/eval_RGS_Net_V3_1.py \
    --fire-category $cat \
    --save-dir output/RGS_Net_V3_1/voting_very_few
done
```

```bash
  --batch-size 32 \
  --fire-category very_few
```
